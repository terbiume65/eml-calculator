The two-button calculator

eml(x, y) = ex − ln y, plus the constant 1, generates the whole scientific calculator. Press 1 to place a one; press eml to split a gap into two. Every expression is a binary tree of identical nodes.

The operator and its identities come from Andrzej Odrzywołek, All elementary functions from a single operator (arXiv:2603.21852, 2026). The two-button calculator framing is from Numberphile's video on the paper.

These values are substituted for x and y whenever an expression contains a variable. Load ln x from the conversions and it evaluates at x = 2; load x − y and it uses both.

Click a gap (?) to select it. Keys: 1, E, X, Y, Backspace.

Conversions

Press a conversion to load it, then edit it with the two keys. K is the number of RPN tokens.

The grammar is S → 1 | eml(S, S). There is no subtraction, multiplication, sine or π key: those are trees. For example e = eml(1, 1), ex = eml(x, 1), and ln x = eml(1, eml(eml(1, x), 1)).

Internally the calculator works over the complex numbers with the principal branch of the logarithm, so expressions can pass through i on their way to a real answer. Values shown are double-precision; chains are the paper's compiler constructions, not always the shortest known forms.

A toy implementation of the EML operator. The mathematics is Odrzywołek's; any bugs are the calculator's.
